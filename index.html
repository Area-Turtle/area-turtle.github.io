  • REST API Testing – Tested CRUD operations including GET, POST, PUT, PATCH, and DELETE using Postman and Newman.

  • CI/CD Pipeline – Integrated GitHub Actions for unit tests, Newman API tests, Playwright E2E tests, linting, and security audits.
  • Security & Code Quality – Added ESLint and npm audit checks.

Built with: Node.js v24, JavaScript, Express.js, Postman, Newman, Playwright, Jest, GitHub Actions, HTML, CSS
